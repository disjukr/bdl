# @disjukr/bdl-runtime

Browser-compatible data schemas, JSON/POJO/text serialization, validation, and fetch RPC runtime for BDL-generated TypeScript. ESM JavaScript and declarations are published under the existing subpath imports, for example `@disjukr/bdl-runtime/data-schema`.

From the repository root: `pnpm build`, `pnpm typecheck`, and `pnpm test`.
